🍪 쿠키 정책

이 웹사이트를 방문할 때 브라우저에 무엇이 저장되는지, 그리고 이유.

업데이트: 2026년 11월 8일

요약
이 웹사이트는 자체 분석용·광고용 쿠키를 쓰지 않아요. 환경설정(테마, 언어, 닫은 알림)과 이 정책에 대한 선택을 브라우저에 저장해요. 타사 위젯 StartupBar는 '동의'를 눌렀을 때만 불러와요.

저장되는 것

모든 것은 브라우저의 로컬 저장소(localStorage 또는 sessionStorage)에 있어요. 이 웹사이트는 자체 HTTP 쿠키를 쓰지 않아요.

환경설정 (동의 불필요)

웹사이트를 쓰면서 직접 요청한 것이라 저장해요. 누구도 식별하지 않고 브라우저 밖으로 나가지 않아요.

  • lm-theme · localStorage · 밝은 테마인지 어두운 테마인지 기억 · 지울 때까지.
  • lm_lang · localStorage · 선택기에서 고른 언어를 기억 · 지울 때까지.
  • promo-dismissed · localStorage · 상단 바를 닫았다는 것을 기억 · 지울 때까지.
  • lm_consent · localStorage · 쿠키 알림에서의 선택을 버전·날짜와 함께 저장 · 바꾸거나 지울 때까지.

동의한 경우에만

'동의'를 누르면 다음 타사 항목을 불러와요. '거부'를 누르면 아무것도 불러오지 않고 웹사이트는 똑같이 작동해요.

  • StartupBar (startupbar.co) · 타사 iframe을 쓰는 위젯으로, sessionStorage에 startupbar:sid를 저장하고(탭을 닫을 때까지) 노출 신호를 보내요. 웹사이트의 모든 페이지에서 불러와요.
  • EmailJS (cdn.jsdelivr.net) · 문의 페이지의 라이브러리로, jsDelivr에서 제공해요.

하지 않는 것

자체 분석, 광고, 프로파일링, 추적 쿠키를 쓰지 않아요. 데이터를 팔지도 않아요. 웹사이트는 GitHub Pages에서 호스팅되며, 페이지를 제공할 때 GitHub의 정책에 따라 IP가 기록될 수 있어요.

선택 바꾸기

어느 페이지든 푸터의 '쿠키 환경설정'에서 언제든 바꿀 수 있어요. 브라우저 설정에서 이 웹사이트의 데이터를 지울 수도 있어요. 동의를 철회하면 페이지가 타사 항목 없이 다시 불러와져요.
