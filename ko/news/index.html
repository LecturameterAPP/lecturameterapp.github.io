소식

Lecturameter에 새로 추가된 것들.

패치 노트 v3.9 / iOS 1.1.0

Lecturameter에 새로 추가된 것들.

새 기능

  • 이벤트: 전 세계 독서 챌린지와 진행 중일 때 Lecturameter Quest
  • 빠른 메뉴: 홈으로 돌아가지 않고 점 세 개(···)로 섹션 간 이동
  • 일시중지: 통계를 망치지 않고 책을 잠시 옆에 두세요
  • 새로운 Pro 테마 2개: 공책과 숲
  • Pro 테마를 미리 보기와 함께 하나씩 또는 3개 묶음으로 구매할 수 있으며, Pro 화면도 새로워졌습니다
  • 선집과 시집을 위한 비선형 독서: 겹치는 페이지는 두 번 계산되지 않으며 진행 막대가 구간으로 나뉩니다
  • 앱을 열지 않고 책 위젯에서 바로 독서 시작
  • 새 디자인과 더 많은 통계를 담은 주간·월간 요약
  • “의견 보내기”의 선택 이메일, 답장을 드리기 위한 용도로만 사용됩니다
  • 테마마다 전용 타이머 시계
  • Pagi가 읽고 싶음에서 책 한 권을 골라 줍니다
  • KOReader의 실제 독서 시간을 반영하는 KOSync
  • 카테고리별 알림과 앱 소식 알림
  • 목표, 내 독서, 도구로 레일이 그룹화된 홈
  • 책의 빠른 작업에서 상태를 바꾸고, 실수하면 되돌리기
  • 이모지 대신 Material 아이콘, 모든 테마에서 더 읽기 쉬운 통계
  • 검색에서 책을 추가할 때 알림
  • 독서 주기 날짜를 한 줄로 모아 더 쉽게 편집
  • 크기별 24가지 템플릿의 빙고
  • iPhone에서 타이머의 Live Activity가 테마 색상으로 표시
  • 카탈로그가 결과 없는 검색과 ISBN 스캔에서 학습하여 없는 책을 추가합니다(11월 15일부터)
  • 중국어 번체
  • CSV에 시리즈 포함

수정 사항

  • 빙고, Wrapped 등 화면의 제목이 다른 메뉴와 같은 높이로 맞춰집니다
  • 빙고와 Wrapped 아이콘의 색상이 복원됩니다
  • 홈의 상태별 책 카운터가 다크, OLED, 황혼, 오로라, 가죽에서 더 잘 보입니다
  • 데이터가 누락된 책의 경고를 하나로 통합: 노란 삼각형은 사라지고 빨간 삼각형만 남습니다
  • 표지와 장르 다시 불러오기에서 이미 모두 정상이면 알려주고, 찾지 못한 항목이 있으면 빨간색으로 경고합니다
  • 매우 큰 라이브러리의 Google Drive 백업이 메모리 부족으로 실패하지 않습니다
  • iPhone의 여러 가지 수정

새 기능
  • % 진행률: 책, 만화책, 만화, 오디오북에서 세션을 퍼센트로 기록하세요. 오디오북에는 시간도 함께 적을 수 있어요.
  • 책, 만화책, 만화, 오디오북을 추가한 뒤에도 형식을 바꿀 수 있어요. 세션, 노트, 통계는 그대로 유지돼요.
  • 세션을 마칠 때 여러 개의 노트와 인용구를 각각 따로 남길 수 있어요.
  • 저장하지 않고 세션을 나가면 임시 저장본으로 보관되고, 다음에 세션을 저장할 때 복구할 수 있어요.
  • 통계: 읽은 책을 형식별로 보여 주는 도넛 차트와 각 유형을 따로 볼 수 있는 형식 필터.
  • 오디오북 챌린지(들은 시간과 완독한 오디오북)와 오디오북 Bingo: 1시간 청취는 30페이지로 계산돼요.
  • Pagi가 어떤 테마와도 어울리는 애니메이션 계절 의상 7종, 새 스킨 9종(음유시인, 밤도둑, 뱀파이어 백작, 잠수함 함장, 잉크, 종이접기, 밤의 독서가, 방랑 기사, 레트로 우주인), 스킨마다 고유한 탭 애니메이션과 함께 첫선을 보여요. 앱 안에 비밀 스킨도 숨어 있어요. 메인 화면을 여기저기 눌러 찾아보세요.
  • Pagi 전용 설정 메뉴가 생겼어요. 자동 계절, 계절 외 시즌 의상, 스킨을 설정할 수 있어요.
  • Pro용 앱 아이콘: 설정에서 원하는 아이콘을 고르세요. 핼러윈, 크리스마스, 새해 버전이 있어요. 자동 계절 변경을 켜면 해당 기간에 아이콘이 바뀌었다가 다시 내가 고른 아이콘으로 돌아와요. 기본값은 꺼짐이에요.
  • Android에서는 Pro를 체험해 보셨다면 Pro 아이콘 중 하나도 선물로 받아요.
  • KOSync(KOReader 및 호환 앱)로 전자책 리더와 진행 상황을 동기화하세요. 단계별 마법사가 안내해 드려요.
  • 이제 앱이 아랍어, 히브리어, 페르시아어, 우르두어로도 제공되며, 오른쪽에서 왼쪽으로 읽는 화면을 지원해요. 책을 직접 추가할 때 책 언어로도 고를 수 있어요.
  • 새로운 Pro 타이머 사운드와 새 카테고리 Cozy가 추가됐어요.
수정 사항
  • 모든 종류의 책에서 장르를 더 잘 고를 수 있어요.
  • 데이터를 더 쉽게 구분할 수 있도록 일부 통계 색상을 바꿨어요.
  • 전자책 리더의 책에 제목이 없으면 코드 대신 읽기 쉬운 이름이 표시되고, 사용자 계정으로 진행 상황이 오지 않으면 마법사가 알려 드려요.
  • 이제 Bingo가 모든 언어로 번역돼요.
  • 모든 언어를 검토했어요. 영어나 스페인어로 나오던 문구가 이제 내 언어로 표시돼요.
  • 저장에 실패해도 휴대폰에 저장한 백업이 비어 버리지 않아요.
  • 책의 상태를 바꿔도 이전 독서 날짜가 지워지지 않아요.
  • 월간 요약에 세션이 없는 완독 도서도 포함돼요.
새 기능
  • Lecturameter가 TestFlight를 통해 iPhone 베타로 나왔어요
  • 코믹스, 만화, 오디오북도 책과 똑같이: 하나의 직접 입력 양식으로 추가하거나 여러 개를 한꺼번에 추가하고, 오디오북 카드도 공유하세요
  • 다른 앱(Goodreads, StoryGraph, Bookmory, Fable)에서 미리보기와 함께 서재 가져오기
  • 시리즈 보기: 책을 시리즈별로 묶어 보여 주고, 책을 추가하면 시리즈가 자동으로 채워져요
  • 공유 카드가 있는 월간 요약, 그리고 Wrapped의 “달마다 나의 책”
  • 통계에 독서 변화 추이 추가
  • 내 카드: 공유한 모든 카드를 한곳에
  • 챌린지 위젯과 Bingo 위젯
  • 검색에서 여러 권을 한꺼번에 추가
  • 서재의 고급 필터
  • 판본별 참여자: 낭독자, 번역가, 일러스트레이터
  • Pro는 Android와 iOS를 합쳐 최대 3대의 기기에서 사용 가능
  • 이제 백업에 태그와 알림도 저장돼요
  • 이제 페이지 없이 시간만으로도 독서 세션을 저장할 수 있어요(전자책으로 읽을 때 편리해요)
수정 사항
  • 여러 권을 삭제해도 실행 취소는 한 번만
  • 문구에 종류가 표시돼요: 책, 코믹스, 만화 또는 오디오북
  • 스크롤할 때 별점 줄이 더 이상 점수를 매기지 않아요
  • 긴 노트가 전부 표시돼요
  • 날짜와 백업 오류가 앱 언어로 표시돼요
  • Drive에서 복원할 때 더 이상 엉뚱한 파일을 고르지 않아요
  • 일부 상황에서 저자 링크를 누르면 앱이 종료되던 문제 수정
  • 더 명확해진 가져오기와 내보내기 안내
  • 백그라운드에서 타이머가 예기치 않게 종료되던 문제 수정
  • Pro 구매 시와 일부 위젯에서 앱이 예기치 않게 종료되던 문제 수정
  • 코믹스와 만화 검색 결과의 헷갈리는 숫자 수정
새 기능
  • 설정을 섹션별로 재구성
  • 태그 기능(책당 최대 3개, #으로 검색)
  • 책 카드와 상세 화면 개편, 카드 크기 4가지
  • 반 별까지 매기는 5점 별점
  • 노트를 인용구, 노트, 감상으로 분리
  • 책, 챌린지, Bingo, 히트맵, 통계 공유
  • 맞춤 독서 알림
  • Pro용 노을 테마
  • 40개 언어 지원
수정 사항
  • 가로 모드와 큰 화면에서 더 나은 레이아웃
  • 더 빠르고 안정적인 책 검색
  • 월별 비교가 있는 Pro 위젯
  • 삭제 같은 작업을 실행 취소 가능
  • 설정 > 도움말에서 팁 초기화
  • Pagi가 더 이상 제목을 가리거나 설정에 나타나지 않아요
새 기능
  • 몰입 세션의 사운드 바가 이제 가로 모드에서도 펼쳐지고, 이전/다음과 반복/순서 재생 제어가 생겼어요
  • 소리 그룹이 테마의 강조 색상을 더 잘 드러내요
수정 사항
  • 휴대폰과 다른 언어로 앱을 써도 가로 모드가 세로로 고정되지 않아요
  • 펼쳤을 때 사운드 카드와 타이머 버튼 사이 여백이 넉넉해졌어요
